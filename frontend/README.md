# Mindshare frontend

The React and TypeScript client for [Mindshare](../README.md). It provides the sign-up and login pages, idea board, and member management UI. GraphQL requests use Apollo Client and are currently sent to `http://localhost:4000/graphql`.

From this directory, install dependencies and start the Vite development server:

```bash
pnpm install
pnpm dev
```

See the [project README](../README.md) for the full local setup, including the backend and database.
